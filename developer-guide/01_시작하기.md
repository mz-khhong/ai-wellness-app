## 1. 환경 설정

### 1.1. Podman 설치

Docker Desktop은 기업 환경에서 특정 조건 만족 시 라이센스를 구매하여야 하므로 Podman 사용을 권장합니다.

**macOS에서 Podman을 처음 사용하는 경우:**
```bash
# Podman Machine 초기화 (최초 1회)
podman machine init

# Podman Machine 시작
podman machine start
```

### 1.2. IntelliJ 코드 스타일 적용

1. **IntelliJ IDEA 설정 열기**
   - `Preferences` (macOS: `Cmd + ,`) 또는 `Settings` (Windows/Linux: `Ctrl + Alt + S`)

2. **코드 스타일 가져오기**
   - `Editor` → `Code Style` → `Java`
   - 톱니바퀴 아이콘 클릭 → `Import Scheme` → `IntelliJ IDEA code style XML`
   - `developer-guide/intellij-settings-code-style.xml` 파일 선택

3. **코드 포맷팅**
   - 프로젝트 전체: `Code` → `Reformat Code` (또는 `Cmd + Alt + L` / `Ctrl + Alt + L`)

**참고**: 코드 스타일 파일은 `developer-guide/intellij-settings-code-style.xml`에 위치합니다.

## 2. 데이터베이스 및 인프라 설정

### 2.1. PostgreSQL 및 Kafka 컨테이너 실행

**Podman 사용 시 (권장)**
```bash
# PostgreSQL, Zookeeper, Kafka 컨테이너 실행
podman compose -f docker-compose.yaml up -d

# 실행 중인 컨테이너 확인
podman ps
```

**실행되는 서비스:**
- PostgreSQL (포트: 5432)
- Zookeeper (포트: 2181)
- Kafka (포트: 9092)

### 2.2. 데이터베이스 초기화

```bash
# 테이블 생성
podman exec -i ai-wellness-postgres psql -U aiuser -d aiwellnessdb < scripts/01_create_tables.sql

# 테스트 데이터 삽입
podman exec -i ai-wellness-postgres psql -U aiuser -d aiwellnessdb < scripts/02_insert_test_users.sql
```

### 2.3. 접속 정보

- **host / port**: `localhost:5432`
- **username**: `aiuser`
- **password**: `mzaiuser@@`
- **database**: `aiwellnessdb`

### 2.4. 컨테이너 관리

```bash
# 실행 중인 컨테이너 확인
podman ps

# 컨테이너 로그 확인
podman logs ai-wellness-postgres
podman logs ai-wellness-kafka
podman logs ai-wellness-zookeeper

# 실시간 로그 확인
podman logs -f ai-wellness-postgres
podman logs -f ai-wellness-kafka

# 컨테이너 중지
podman compose -f docker-compose.yaml down

# 컨테이너 중지 및 볼륨 삭제
podman compose -f docker-compose.yaml down -v
```

### 2.5. Kafka 토픽 확인

```bash
# Kafka 컨테이너에 접속하여 토픽 목록 확인
podman exec -it ai-wellness-kafka kafka-topics --bootstrap-server localhost:9092 --list

# 특정 토픽 상세 정보 확인
podman exec -it ai-wellness-kafka kafka-topics --bootstrap-server localhost:9092 --describe --topic wellness-message-event

# 토픽 생성 (필요한 경우)
podman exec -it ai-wellness-kafka kafka-topics --bootstrap-server localhost:9092 --create --topic wellness-message-event --partitions 1 --replication-factor 1
```

## 3. 프로젝트 실행

### 3.1. 프로젝트 빌드

```bash
./gradlew clean build
```

### 3.2. 서버 실행

각 서버를 별도의 터미널에서 실행합니다:

```bash
# 터미널 1: Admin Server
./gradlew :admin-server:bootRun

# 터미널 2: Manager Server
./gradlew :manager-server:bootRun

# 터미널 3: Customer Server
./gradlew :customer-server:bootRun
```

### 3.3. Swagger UI 접근

각 서버가 실행되면 다음 URL로 접근할 수 있습니다:

- **Admin Server**: http://localhost:8080/swagger-ui.html
- **Manager Server**: http://localhost:8081/swagger-ui.html
- **Customer Server**: http://localhost:8082/swagger-ui.html

## 4. API 테스트

### 4.1. 로그인 (JWT 토큰 발급)

```bash
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@example.com",
    "password": "password123"
  }'
```

### 4.2. 관리자 조회 (인증 필요)

```bash
curl -X GET http://localhost:8080/api/admins/1 \
  -H "Authorization: Bearer {JWT_TOKEN}"
```

### 4.3. Swagger UI에서 테스트

1. Swagger UI 접속
2. `/api/v1/auth/login` 엔드포인트로 로그인하여 토큰 발급
3. 상단의 **"Authorize"** 버튼 클릭
4. `Bearer {token}` 형식으로 토큰 입력
5. 인증이 필요한 API 테스트 가능
